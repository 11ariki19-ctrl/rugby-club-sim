# 栄冠ラグビー：ラグビー人生キャリア

高校1年生の選手として競技人生を始め、高校・大学・社会人・日本代表・ワールドカップを目指すラグビー専用のキャリアシミュレーションです。iPhone Safari と PC ブラウザに対応し、ブラウザ内にキャリアを保存します。

## 開発

- TypeScript / Vite
- `npm install`
- `npm test`
- `npm run build`
- `npm run dev`

## ゲームの入口

アプリ起動時はラグビー人生キャリアを直接開きます。旧来の部活監督モードのタイトル画面は起動しません。サッカー・野球モードは本作の対象外です。

## 公開

GitHub Actions の Pages ワークフローが `main` への push 時にテスト・型チェック・ビルドを実行し、成功後に GitHub Pages へデプロイします。

## 実名校・大会データ

- 高校の選択肢は都道府県別の実在校データを使用し、花園の直近10大会（2016〜2025年度）の決勝結果を評価へ反映します。
- 大学は関東大学対抗戦A/B、関東大学リーグ戦1部/2部、関西大学A/Bリーグの6グループを選択可能です。リーグ戦は8校の総当たり7試合、成績に応じて大学選手権または昇降格入替戦へ進みます。
- 2025年度の全国大学選手権は14チームのトーナメントを参考に、12月の3回戦・準々決勝、1月の準決勝・決勝へ進行します。
- 2025-26シーズンは独立した「日本選手権」大会が行われていないため、社会人の国内タイトルはリーグワンD1プレーオフをモデルにしています。
- 参考資料：全国高校ラグビー歴代決勝結果（https://rugbydb.tokyo/list/hanazono_final.html）、第62回全国大学選手権大会概要（https://www.rugby-japan.jp/news/53574）、関東大学対抗戦Bグループ2025（https://www.rugby.or.jp/univ/result/2804/）、関東大学リーグ戦2025（https://www.kurfa.org/leaguerugby_list/?season=2025）。

※都道府県別高校一覧は、現時点で収録した実在校の選択データです。過去10年の各都道府県予選に参加した全校の網羅を保証する完全な年次台帳ではありません。未収録校のない完全版にするには、各都道府県の予選全年度記録を追加照合する必要があります。
