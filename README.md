# 高校スポーツ部監督物語

高校の部活動を運営し、選手を発掘・育成しながら大会を勝ち抜き、卒業生の大学・プロ・代表キャリアを追う長期運営シミュレーション集です。

## ゲーム

- [高校ラグビー部監督物語](./) — 47都道府県の高校から開始。月次育成、県予選・花園、大学ラグビー、リーグワン、代表選考、国際試合、引退後までの長期キャリア。
- [高校サッカー部監督物語](./public/soccer/index.html) — 11人制、布陣・戦術、交代、疲労・負傷、スカウトと勧誘、県大会・地域大会・インターハイ・高校サッカー選手権・U-18リーグと全国大会、U-18日本代表のアジア/世界大会、大学・Jリーグ進路。
- [高校野球部監督物語](./public/baseball/index.html) — 打順・守備・投手起用、投球数と疲労、四球・死球・三振・盗塁・犠打・犠牲フライ・失策・併殺、春季県大会/地区大会、選抜高校野球、夏の県予選・49代表の夏の甲子園、秋季大会・地区大会、明治神宮大会、国民スポーツ大会、侍ジャパンU-18のアジア/世界大会、大学・NPB進路。

## 共通機能

- 選手の能力・才能に応じた成長と卒業後の進路記録
- 大会の組み合わせ、勝ち上がり、出場資格、結果履歴
- 全国チームランキング、代表候補選考、国際大会
- ブラウザ自動保存、手動3枠セーブ、JSONバックアップ/復元
- スマートフォンでも操作しやすい画面

## 開発

`npm install` → `npm test` → `npm run build` → `npm run dev`

サッカー版と野球版は独立した静的ページとして `public/` 以下に配置され、GitHub Pages では `/soccer/` と `/baseball/` からプレイできます。
