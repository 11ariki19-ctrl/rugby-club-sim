# 高校ラグビー部監督物語

ラグビーの高校チームを運営する、観戦なしの育成シミュレーションです。
スカウトで選手を集め、3年で卒業していく部員の進路を見届けます。

- 開始時に47都道府県から高校を選ぶ
- チーム強化はスカウトのみ（試合は自動で進行）
- 卒業時の能力で、名門大学などの進路が決まる
- データはブラウザ内に保存

開発: `npm install` → `npm test` → `npm run dev`

## 追加ゲーム

- [高校サッカー部監督物語](./public/soccer/index.html)：選手育成・布陣/戦術・県大会・夏の全国大会・冬の全国選手権・卒業後進路・全国ランキング・3枠セーブ/JSONバックアップ
- [高校野球部監督物語](./public/baseball/index.html)：選手育成・イニング進行・四球/盗塁/犠打/失策・投手交代・打順管理・県大会/夏の全国大会・卒業後進路・全国ランキング・3枠セーブ/JSONバックアップ

Vite のビルド成果物には `public/` 以下が含まれます。GitHub Pages 公開後は `/soccer/` と `/baseball/` からプレイできます。

## 大会・キャリア機能

サッカー版は県大会で優勝すると夏の全国大会へ、秋の県大会で優勝すると冬の全国選手権へ進出できます。野球版は夏の県予選を優勝すると49校参加の全国大会に進めます。両版とも大会の勝ち上がり、卒業生の進路記録、全国チームランキング、手動3枠セーブとJSONの書き出し/読み込みに対応します。ブラウザのIndexedDBにも自動バックアップを保存します。
